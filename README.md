# math-visuals · 数学图示

给孩子的**动态交互数学图示**集合。每个图都是一个**离线单文件 HTML**：双击即开、可发平板、断网可用。

> 打开 `index.html` 即为导航首页（可搜索、按知识点分组）。

## 怎么用

- **看**：浏览器打开 `index.html`，点卡片进入任一图示。
- **加新图**：复制 `00-模板/template.html` → 放到对应知识点文件夹 → 改文件名/标题/元信息 → 跑 `python3 tools/build_index.py` 重建首页。
- **规范**：见 [`docs/CONVENTIONS.md`](docs/CONVENTIONS.md)。

## 知识点分类

| 文件夹 | 知识点 | 说明 |
|--------|--------|------|
| `01-角` | 角 | 角的度量、倍数关系、平角/周角 |
| `02-函数` | 函数 | 正比例/反比例、图象 |
| `03-分数与小数` | 分数与小数 | 分数意义、小数、互化 |
| `04-面积与体积` | 面积与体积 | 周长/面积/体积公式 |
| `05-统计与图表` | 统计与图表 | 条形图/折线/扇形图 |
| `06-数与运算` | 数与运算 | 数的认识、四则运算 |
| `07-应用题` | 应用题 | 行程/工程/和差倍等 |

> 新增分类：在根目录建 `<序号>-<知识点>/`，并同步更新本表。

## 目录结构

```
math-visuals/
├── index.html             # 导航首页（自动生成）
├── 00-模板/template.html  # 新图复制起点
├── 01-角/ …               # 按知识点分文件夹
├── tools/build_index.py   # 索引生成器
└── docs/CONVENTIONS.md    # 规范
```

## 本地运行

```bash
# 重建导航首页
python3 tools/build_index.py

# 直接看（二选一）
xdg-open index.html          # 或直接双击
python3 -m http.server 8000  # 起本地服务（可选）
```
